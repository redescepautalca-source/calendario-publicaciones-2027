¿Cómo funciona la lógica de fechas?

  • 1. Cálculo de Inicio del Programa: Si ingresas sólo un mes (ej. Mes desde = 6, Mes hasta = 6), el sistema toma el día 15 de ese mes. Si ingresas un rango de meses (ej. Mes 1 a 3), calcula automáticamente el punto medio exacto entre el primer día del mes inicial y el último día del mes final.
  • 2. Fecha Definitiva: Cuando confirmes el día exacto de inicio de un Curso o Charla, ingrésalo en Fecha definitiva; reemplazará automáticamente la aproximación en todas las vistas.
  • 3. Prioridad de Fecha Editorial: En la Agenda o haciendo clic en cualquier publicación puedes fijar una Fecha Editorial. Esta tiene prioridad sobre la fecha calculada por reglas. Si la borras, vuelve a regir la fecha automática.
  • 4. Anticipaciones en 2026: Los programas que inician a comienzos de 2027 (como Primeros Auxilios Psicológicos) generan publicaciones en noviembre y diciembre de 2026. Usa el selector superior Año vista: 2026 / Todos para revisarlas.

¿Cómo alojar y compartir esta plataforma?

Esta aplicación es un archivo web autónomo (.html) sin dependencias externas de servidor:

  • • Alojamiento Web Gratuito: Puedes subir este archivo directamente a Netlify Drop (arrastrando el archivo), GitHub Pages, Vercel o el servidor/intranet de la universidad.
  • • Persistencia Automática: Todos los cambios que realices se guardan al instante en el navegador (localStorage).
  • • Trabajo en Equipo: Usa el menú Datos / Exportar → Guardar Respaldo (.JSON) para compartir tu estado actualizado con otros miembros del equipo o exportar la tabla a Excel (.CSV).

☁️ Sincronización en la Nube para Trabajo en Equipo

Conecta la plataforma alojada en GitHub Pages a un almacenamiento compartido para que todo el equipo vea y edite los mismos datos.

¿Cómo funciona? Al presionar Publicar, la página guarda un archivo datos.json directamente en tu repositorio de GitHub mediante la API oficial, manteniendo historial de versiones (commits).

El token se guarda únicamente en el navegador de cada integrante (nunca se sube al código público).

Ideal para equipos no técnicos: Crea un proyecto en script.google.com, pega el código de abajo, publícalo como Aplicación web (Acceso: Cualquier persona) y pega aquí la URL generada.
Código listo para pegar en Google Apps Script (Código.gs): 
function doGet() {
  var prop = PropertiesService.getScriptProperties().getProperty('CALENDARIO_DATA') || '{}';
  return ContentService.createTextOutput(prop).setMimeType(ContentService.MimeType.JSON);
}
function doPost(e) {
  PropertiesService.getScriptProperties().setProperty('CALENDARIO_DATA', e.postData.contents);
  return ContentService.createTextOutput(JSON.stringify({ok: true})).setMimeType(ContentService.MimeType.JSON);
}
Base de datos JSON directa: Ingresa la URL de tu base de datos en tiempo real (por ejemplo, Firebase Realtime Database terminada en /calendario.json). La app hará GET para leer y PUT para guardar.
